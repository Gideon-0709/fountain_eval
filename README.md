# fountain_eval

Fountain 系列 engine、scheme 和 operator 的独立标准测试基础设施。

本仓库当前保存团队已确定的架构设计，尚未实现测试程序。具体测试内容、测试矩阵、命令行和文件 schema 将在后续设计中确定。

## 测试条件模型

每项实验由四元组 **`(C, I, T, E)`** 描述：

| 维度 | 含义 |
|---|---|
| C：组件版本集合 | 被测 engine、scheme、operator、utility 及实际运行依赖 |
| I：测试接入版本 | 对接组件 API 的实际适配实现及能力映射 |
| T：测试版本 | 测试内容、执行流程、计时范围、指标、验证规则和固定资产 |
| E：实验配置 | 工作负载参数、输入选择、构建配置、工具链和运行环境 |

**T 和 E 相同、接入语义等价时，不同 I 下的组件结果仍然可以比较。** 四元组标识实验条件；运行编号和原始样本区分相同条件下的多次执行。

## 设计入口

阅读 [DESIGN.md](DESIGN.md)，了解现有库的依赖关系、独立测试仓库的模块边界、版本管理、可比性与归因规则，以及开发者和维护者的协作流程。

本仓库独立管理 I 和 T，不使用额外的统一对外协议发布号取代四元组。被测实现通过版本化驱动接入，公共测试核心保持对具体 fountain 实现的独立性。
