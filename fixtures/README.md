# Deterministic assets and fault fixtures

The acceptance source bytes, trace and scalar GF oracle are generated by the embedded `drivers/common.rs` code and are included in T's content digest. No external benchmark corpus is needed.

Framework tests create temporary synthetic requests and evidence to check parsing, units, snapshots, protocols and rejection rules. The native acceptance script creates isolated wrong-result, compile-failure, crash and hanging operator fixtures under its own work directory. Synthetic fixtures are labeled tests of the framework and are never presented as codec performance measurements.
